# PARSU Student Appointment and Queue Management System

A Week 14 static prototype for Partido State University students and university-office staff. The system lets students browse services, request appointment slots, and follow queue status while staff review requests and manage service schedules.

## Week 14 deliverables

- `docs/01-brief.md` — project brief
- `docs/02-crud-map.md` — table-to-page CRUD map and field controls
- `docs/03-sitemap.png` and `docs/03-user-flow.png` — navigation and booking flow
- `docs/04-wireframes/` — desktop and phone wireframes
- `docs/05-style-guide.md` — visual system
- `prototype/list.html` and `prototype/form.html` — static pages using `prototype/css/style.css`
- `database/schema.sql` and `database/seed.sql` — Week 15 database foundation

## Users

- Students: browse services, request appointments, and monitor queue status.
- Office staff: review requests, confirm or cancel appointments, assign queue numbers, and maintain schedules.
- Administrator: manage offices, services, schedules, and staff access.

## Note

The `prototype/` pages are intentionally static. PHP, MySQL connections, and JavaScript validation belong to Week 15.
